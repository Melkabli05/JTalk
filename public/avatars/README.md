# Profile pictures

Ten pictures people can choose from in the profile dialog, referenced by id (`avatar-01` … `avatar-10`, see `src/app/shared/utils/avatars.ts`).

- Style: **Lorelei** by Lisa Wischofsky, from [DiceBear](https://www.dicebear.com/styles/lorelei/).
- Licence: **CC0 1.0** (public domain), so they can be used and changed without credit.
- Made with the DiceBear HTTP API (`https://api.dicebear.com/9.x/lorelei/svg`), one seed each, happy mouths only, a flat Bauhaus-colored background. They are bundled here so the app never calls an outside service.

To change them, replace the files (keep the names), or add more and list them in `avatars.ts`.
